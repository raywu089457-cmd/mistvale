把暮影村
加到你的主畫面

免 App Store、免 Apple 帳號、免付費。裝完桌面會出現「暮影村」圖示，點開就是全螢幕遊戲。

  1. 按下面的 「加入主畫面」 按鈕。
  2. 如果跳出「要下載設定描述檔嗎」→ 選 允許。
    如果沒跳出、只是開始下載檔案 → 打開 檔案 App → 下載項目 → 點 mistvale.mobileconfig。
  3. 打開 設定（最上方會出現「已下載描述檔」）→ 安裝 → 輸入你的手機解鎖密碼 → 再按 安裝。
  4. 回到桌面，就會看到 「暮影村」 圖示 🎮 點開即可遊玩。
📲 加入主畫面（下載描述檔） 只想先在瀏覽器裡玩 →
為什麼要到「設定」裡安裝？ 這是蘋果對「主畫面捷徑」的規定，免帳號的做法一定要到設定確認一次。裝完就是常駐的圖示。

注意：因為蘋果對網頁的要求，有時候點按鈕會直接下載一個 .mobileconfig 檔（而不是跳出授權框）——那是正常的，照上面第 2 步去「檔案」App 開它就好。
• 這是一個「主畫面捷徑」（Web Clip），圖示點開全螢幕執行網頁遊戲，會自動存檔。
• 想刪除：長按桌面圖示 → 移除 App；或到 設定 → 一般 → VPN與裝置管理 刪除描述檔。
• 免費、免 Apple Developer、不上架、不追蹤。
• 存檔在這台裝置的瀏覽器裡，建議偶爾用遊戲內「設定 → 匯出存檔」備份。
