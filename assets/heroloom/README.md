# Heroloom — Free

A free sample of the Heroloom modular pixel character system: 23 parts, the body, all 8 animations and the Character Maker.

Open `maker.html` in a browser, pick parts and colours, and save a sprite sheet (PNG) with frame data (JSON).

- Cell 64×56 px, 8 columns, one row per animation (idle, walk, attack, hurt, jump, cast, thrust, shoot); sprites face right
- `character.json` describes slots, layers, palettes and timing; `runtime/js/paperdoll.js` builds characters at run time
- Same format as the full packs, so everything made here keeps working when you add them

The full version has 998 parts across nine packs, plus kits for Godot, LÖVE and Unity: https://ljs0218.itch.io/heroloom
