# 暮影村 · 像素獵魔物語 v1.5.0

原創繁體中文像素村莊經營與自動狩獵遊戲。這不是原作的拷貝，沒有使用原作程式、商標或官方素材；建築採用本專案生成的獨立像素素材，角色與地景由程式繪製；圖像來源記錄在 `assets/PROVENANCE.md`。

## 玩法

重建城鎮大廳、交易所、餐廳、旅館、酒館、治療所、鐵匠鋪、學院、修煉地、復活聖所、獵人小屋、委託所、強化精煉所和地下城入口。招募有職業、稀有度、性格和個人金幣的獵人，他們會自動狩獵、交易、吃飯、喝飲品、睡床、治療與購買裝備。

村長可以發布材料收購、製作生活物資、鍛造裝備、教技能、訓練、強化與轉世，完成 8 個委託章節，挑戰森林魔王、地下城和 NPC 競技場。

## 遊玩

用 Chrome 或 Edge 開啟輸出的 `暮影村.html`，按「開始村長生活」。遊戲會每五秒自動存檔，右上設定可匯出 JSON 存檔。

- 拖曳或單指拖曳：平移村莊。
- 滾輪或雙指縮放：縮放像素場景。
- 點建築或獵人：查看資訊與操作。
- `1` 到 `7`：建設、獵人、交易、製作、地下城、競技場、委託。
- `Space`：暫停／繼續。`Esc`：關閉視窗。

## 建置與測試

```sh
npm install
npm test
node test-pixel-game.mjs
npm run build
npm run serve
```

輸出為單檔 `暮影村.html`，伺服器預設 `http://100.79.149.0:5024`。測試涵蓋交易金錢守恆、付費服務、製作、裝備、技能、訓練、轉世、難度、首領、死亡復活、地下城、NPC 競技場、路徑碰撞、存檔續戰與確定性。

主要檔案：`src/pixel-data.js` 資料、`src/pixel-game.js` 模擬、`src/pixel-world.js` 像素渲染、`src/pixel-ui.js` 介面、`src/pixel-index.html` 與 `src/pixel-style.css` 介面結構、`assets/` 圖像素材。

## v1.3 主世界與美術更新

- 地圖座標範圍從 58 × 52 擴展為 87 × 104，矩形範圍面積 3,016 → 9,048，恰為原本三倍。
- 8 個區域：暮影村、向陽草原、橡木密林、霜杉林地、白霜雪原、鐵脊山麓、赤金沙地、白樺花原。不同地表、樹種、礦石、花草、仙人掌、蕈菇、礦坑與遺跡。
- 新增河流與 4 座橋樑；河水阻擋行走，獵人會沿橋通行。所有新狩獵區可派遣、戰鬥、返村服務與存檔續玩。
- 按 M 或右上「主世界地圖」查看區域，按「前往」派遣；左下功能仍保留原有村莊經營系統。
- 接入 ImageGen 大廳與新生成旅館素材，更新瓦片、石材、窗框、花箱、角色細節和物品圖示；建築文字改為更清楚的原生文字。
- 現有 v2 像素存檔自動沿用，不清除獵人、建築與庫存。測試預覽使用 ?preview=world3，不讀寫玩家存檔。
- 這是有限地圖的像素經營遊戲；主世界參考用於生態與地景設計，不含 Minecraft 挖掘、方塊放置或無限生成。

額外測試：`node test-overworld.mjs`。`npm test` 同時執行經營與主世界回歸測試。


## v1.4 房屋、道路與戰鬥視野

- 使用一次生成的一張 4×3 圖集，補齊交易所、餐廳、酒館、治療所、鐵匠鋪、學院、修煉地、復活聖所、獵人小屋、委託所、強化精煉所與地下城的精緻像素素材；14 種設施全部有獨立素材。
- 道路、尋路与植被共用 `src/landscape-layout.js`。石板街連到各建築門前，野外土路連接 4 座橋樑與 7 個狩獵區。搬移或建造設施會重新產生道路和避讓區。
- 角色優先沿道路行走，繞開房屋、噴泉、水井與柵欄；河面只能經由橋樑跨越。戰鬥空地內允許直接移動。
- 每個狩獵區都有固定空地與旗標。怪物生成及追擊範圍限制在空地附近，避免把交戰帶進密林或道路。
- 樹木減量並保留道路與戰場的投影視野：不只檢查樹幹位置，也檢查前景樹冠；偶爾走到樹後的角色會觸發樹冠淡化。
- `test-landscape.mjs` 驗證道路入口、戰場遮擋、場景障礙、怪物範圍、搬屋路線。180 秒模擬中約 99.1% 的非戰鬥移動樣本落在道路範圍，這是特定測試結果而非所有局面的保證。


## v1.5 概念圖對齊

登入概念圖保持原圖不變，遊戲實景以它作為驗收基準：中央英雄雕像廣場、暖色石板、旗幟、花園、燈柱、緊湊但可通行的村莊構圖，以及高密度的房屋細節。

本版改用原生像素解析度渲染，避免低解析度緩衝造成建築縮小和材質丟失。中央廣場、房屋布局、道路和河岸一起調整，讓進入遊戲後的村莊構圖與登入概念圖的視覺重點一致。概念圖與遊戲實景仍是不同用途的原創素材；不能保證逐像素 100% 複製，但已把可驗證的構圖和美術語言對齊。
