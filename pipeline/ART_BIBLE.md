# 暮影村 英雄 Sprite 美術規範(Art Bible)

來源:使用者 2026-10-05 的美術總監規格(Cute modern pixel RPG + mobile idle RPG,參考 EHT / Crusaders Quest / KOF AFK / Guardian Tales / Seven Knights Idle 的設計原理,不複製任何作品)。
決策:**B**(英雄 64–90 px 美術、遊戲裡畫大約 2 倍)、**先做弓箭手(Archer)試點**、**技能是真的遊戲機制**。

核心:SILHOUETTE > DETAIL · READABILITY > COMPLEXITY · CONSISTENCY > INDIVIDUAL DETAIL · ANIMATION > STATIC BEAUTY · MASS PRODUCTION > ONE-OFF ART

## 規格(每一條都有 `pipeline/scripts/check/audit_hero_sheet.py` 的數字檢查)

| 項目 | 規格 | 檢查 |
|---|---|---|
| Canvas | 每格 128×128,1:1 像素,透明背景 | 格尺寸、alpha 只有 0/255 |
| 角色高 | 64–90 px(站姿頭頂到腳底,不含武器) | 待機身高 |
| 頭身 | 2.5–3 頭身 chibi | 人工(提示詞控制) |
| 方向 | 只做朝右(左邊鏡像);4 方向留待需要時 | 每格朝向 = 右 |
| 色盤 | 每個角色 ≤16 色(含描邊),所有格共用一份 | 不重複色數 |
| 描邊 | 深色 sel-out 外框,不是純黑粗線 | 剪影外圈暗色比例 ≥ 0.55 |
| Idle | 4–6 格,幅度小 | 格數、身高變化 ≤ 4 px |
| Walk | 4–6 格完整循環 | 格數 |
| Attack | 6–10 格:預備→後拉→蓄力→出手→命中→收招→回復 | 格數、命中格標記 |
| Skill | 8–16 格,招牌技能 + 像素特效 | 格數 |
| Hurt | 2–4 格 | 格數 |
| Death | 5–8 格 | 格數 |
| Victory | 4–8 格 | 格數 |
| 一致性 | 每格同角色、同服裝、同武器、同配色、同比例;禁止 AI 畫風漂移 | 各格身高 vs 待機 ±12%、對齊(軀幹 x 固定) |
| 不裁切 | 角色、武器、特效都不碰格邊 | 每格四邊留 ≥2 px 透明 |
| 可讀性 | 縮到 50–80 px 仍能一眼看出職業 | 縮成 32 px 剪影跟其他職業的 IoU < 0.8 |

## 職業視覺語言(剪影 + 武器 + 姿勢 + 裝備,不靠顏色)

Knight 大盾+劍+重甲 · Archer 長弓+箭袋+輕裝 · Mage 大法杖+帽子/法袍 · Assassin 雙刀+窄身 · Paladin 巨盾+重甲+金色聖物 ·
Berserker 巨大雙手武器+寬肩 · Priest 聖杖+長袍+光 · Necromancer 黑杖+長袍+骷髏 · Ranger 弓+斗篷+自然元素 · Monk 素衣+空手+武術姿勢

## 模組化

每個英雄 = Base Character(固定頭身與骨架姿勢)+ 頭/髮/臉/身體/鎧甲/披風/武器/盾/飾品/特效。
生圖時第一張「設計表」(idle 4 格)當之後每個動作表的 REF;同一職業的所有動作表共用同一份色盤(從設計表取 16 色)。

## 遊戲內尺寸(決策 B)

美術像素密度跟建築/地面一致:0.62 邏輯單位/美術像素 → 64 px 高的英雄畫 ≈ 40 邏輯單位(舊英雄 21)。
128 格 = 79 邏輯單位。腳底基準 = 格內 y=118(底下留 10 px 給影子/揚塵),軀幹中心 x = 64。
