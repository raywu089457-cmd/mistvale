# T121 首次開局入門嚮導

Status: done
Type: ui / onboarding
Accept: `node tools/checks/welcome.mjs && npm run verify:quick`

## Goal

新玩家打開遊戲直接進村莊，只有左下角一句 log，完全不知道先做什麼（要先派獵人出征才有材料，
要先蓋食堂／旅館／酒館獵人才吃得住得、才會付錢）。這一輪加一個**只會出現一次**的入門嚮導：

- 條件：**沒有存檔** 而且 **不是 `?preview=1`**。老玩家與所有自動化（巡檢、檢查器）完全不受影響。
- 內容：三步驟卡——① 選人出征（地下城每層 3 波）② 把村子蓋起來（食堂／旅館／酒館／治療所）
  ③ 接著看委託與主世界地圖；底部提示列說明「說明」在哪、點單位會開資訊卡。
- 動作：「開始遊戲」關閉並寫入存檔＋一句提示；「看完整說明」直接切到村長入門手札。
- 手機：步驟卡單欄、按鈕整列且 ≥34px 高。

## Files

- `src/pixel-ui.js`：`firstRun` 狀態（讀存檔時記 `!previewMode&&!saved`）、`start()` 後 520ms 彈窗、
  `modalHTML('welcome')` 模板、`modalTitle` 名稱、`doAction` 的 `welcomeStart` / `welcomeHelp`。
- `src/pixel-style.css`：檔尾 T121 區塊（步驟卡、圓章、說明列、按鈕列、手機）。
- `tools/checks/welcome.mjs`（新）。

## Decisions

- **用存檔判斷「第一次」而不是用另一個旗標**：存檔就是玩家真的玩過的證據；另立一個
  `seenWelcome` 反而會出現「存檔沒了但旗標還在」的不一致。
- **`?preview=1` 直接跳過**：23 支檢查器＋按鈕巡檢都靠 preview 進村莊，彈窗會讓它們全部要改。
- **延後 520ms 才彈**：先讓村莊畫一幀、載入畫面收掉，再蓋上嚮導，不會有「兩層遮罩同時在」的閃動。
- **不塞教學任務系統**：只是「說明書」，不追蹤完成狀態；真正的引導仍由村長委託章節負責。
- **「開始遊戲」會寫存檔**：否則玩家按完重新整理又會再看到一次。

## Notes

- 第一次接這個模板時把 `modalHTML` 的結尾錨點寫成兩空格縮排的 `return '';`（那是 `upgradeDelta` 的結尾），
  結果整個 welcome 模板被塞進 `upgradeDelta()` 裡 → 開窗時 `#modal-content` 是空的。
  修法是改用**行號手術**（找到 `if(type==='welcome')` 的起點、用它所在的 `}` 收尾、搬到
  `modalHTML` 那個單空格縮排的 `return '';` 之前）。教訓：同一個 `return '';` 在檔案裡有多份，
  錨點一定要帶足以唯一化的上下文（函式名），或直接做行導向操作。
- 檢查器驗：全新玩家看得到（標題、三張卡、編號 123、提示列、兩個按鈕）、按「看完整說明」會切到說明、
  按「開始遊戲」會關窗＋遊戲開始跑＋寫入存檔＋給提示、重新整理不再出現、`?preview=1` 不出現、手機不溢出。
- 存檔 key 是 `mistvale-pixel-v2`（一開始在檢查器裡寫錯成 `mistvale-v1`，驗證時抓出來）。
