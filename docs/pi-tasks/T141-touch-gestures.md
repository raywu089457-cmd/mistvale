# T141 手機手勢（雙擊縮放／雙指釘住／甩動慣性）

Status: done
Type: ui
Accept: `node tools/checks/touch-gestures.mjs && npm run verify`

## Goal

使用者把目標擴充成「要兼顧手機版本操作順暢」。查過現況：搖桿移動、技能／攻擊鈕、雙指縮放其實
**都已經有了**，真正缺的是手感細節：

1. **雙擊縮放**：手機上放大世界只能按右下角 ＋／−，雙擊是最直覺的手勢，目前完全沒有。
2. **雙指縮放沒有釘住指間**：原本 `zoomBy(dist/pinchDistance)` 是繞著畫面中心縮放，捏合時
   想看清楚的那一點會跑掉。
3. **拖曳放手沒有慣性**：手機上一頁一頁地「推」地圖很累，放手後應該滑一小段再停。
4. 單點選取不能被手勢吃掉。

## Files

- `src/pixel-world.js`
  - 新增 `zoomAt(sx,sy,factor)`：先記下指點的世界座標、縮放、再把鏡頭補回去（跟滑鼠滾輪同一套算法），
    所以「指下的東西不會跑」。
  - 雙指：`move()` 的雙指分支改用 `zoomAt(指間中點, dist/pinchDistance)`。
  - 雙擊：`up()` 記錄上一次觸控點擊的時間／位置；320ms 內、28px 內第二次點擊 → 以該點為中心
    放大 1.25 倍（已到最大則縮小），並且**不觸發選取**。
  - 慣性：`move()` 記錄單指速度（px/ms），`up()` 若為觸控且有位移且不是跟隨模式就留下
    `inertia`；`update()` 以 0.86/16.7ms 指數衰減平移。按下或跟隨時立刻清除。
  - 除錯鉤子 `panState()`（慣性速度與上次點擊時間），只在驗收用。
- `tools/checks/touch-gestures.mjs`（新）：用合成 PointerEvent 在 402x712 觸控環境驗四件事。

## Decisions

- **雙擊一律先放大、到頂才縮小**：手機玩家最常見的意圖是「放大看清楚」，不是縮小。
- **慣性只給觸控**：滑鼠拖曳本來就有滾輪與拖曳，加滑行反而會讓人覺得鏡頭不聽話。
- **慣性用螢幕像素速度換算世界單位**（`/scale`）：放大 2 倍時滑行距離不會變成兩倍。
- **跟隨角色時關掉慣性與雙擊縮放**：操控獵人時鏡頭由角色決定，手勢介入只會抖。
- 雙擊不等於「連點兩次選取」：第二次點擊直接 return，不會同時開面板。
