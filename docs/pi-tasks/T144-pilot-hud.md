# T144 手機「操作獵人」介面不再互壓

Status: done
Type: ui
Accept: `node tools/checks/pilot-hud.mjs && npm run verify`

## Goal

目標要求手機操作順暢。這輪把「操作獵人」（手動操控）模式真正進去看了一次：**離開操控的 ✕ 按鈕
壓在左下搖桿上**——360 寬實測重疊 52px，推搖桿時拇指會去按到「離開」。

## 量到的事實（360×640，操作模式）

| 元素 | 位置 | 尺寸 |
| --- | --- | --- |
| 搖桿 | (16, 494) | 124×124 |
| 技能 / 攻擊 | x158 / x256 | 86×86 |
| ✕ 離開 | (88, 558) | 58×58 ← **與搖桿重疊 52×58** |
| 狀態列 | 頂部整條 | 高 116 |

## Files

- `src/pixel-style.css` 檔尾 T144 區塊：
  `body.piloting #pilot-hud .ph-btn.ghost{position:fixed;right:14px;bottom:calc(24px + 86px + 14px + safe-area);width:52px;height:52px}`
  —— 把 ✕ 移到技能鈕正上方、靠右邊緣；≤400px 縮成 48px。
- `tools/checks/pilot-hud.mjs`（新）：402×712 與 360×640 兩台手機，實際走一次
  「叫出選人清單 → 點第一位獵人 → 操作模式」，量四個控制項的矩形並驗：
  互不重疊、都在畫面內、點得到、技能／攻擊／離開 ≥44px、搖桿 ≥110px、上方狀態列有角色資訊、
  操控中底部村莊按鈕列讓位、按 ✕ 會回到村莊。

## Decisions

- **不把 ✕ 放左上／右上角**：頂部是角色狀態列（整條高 116px），放上去會壓住血條；
  改放「技能鈕正上方、右緣對齊」，拇指伸得到又不在搖桿區。
- **不隱藏狀態列改放按鈕**：狀態列有 HP 與操作提示，是操控時最需要看的資訊。

## Notes

- 這個模式平常要開遊戲、選人、進操作才看得到，之前的 16 面板稽核完全沒涵蓋到；
  `data-action="pilotLab"` 會叫出選人清單，`[data-pilot="go"]` 才是真正開始操控。
- 驗證時 `elementFromPoint` 會先打到按鈕裡的 `<i>`／`<span>`，要用 `closest('button')` 才判斷得出來。
