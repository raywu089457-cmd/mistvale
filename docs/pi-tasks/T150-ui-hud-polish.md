# T150: ui hud polish

Status: done
Accept: npm run verify:quick

## Goal
把遊戲 HUD(頂欄 + 底欄)修到沒有粗糙處,視窗 1024x768 與 1920x1080 都要成立:
- 頂欄最右邊與畫面左上角(頂欄下方)各有一顆沒有圖示也沒有文字的空白按鈕:補上正確圖示與 aria-label/title;若確認沒有功能就移除。
- 頂欄「第 N 天 · 白天」不可換行、不可出現孤立的「.」。
- 頂欄資源格(金幣/星晶/木材/鐵礦)滑鼠移上去要有名稱提示(title 或既有 tooltip 機制)。
- 底欄按鈕文字標籤實際字級 >= 12px 且對比清楚;「已自動儲存」同樣 >= 12px。
- 畫面最底那行操作提示(拖曳平移·滾輪縮放…)目前被底欄裁掉一半:讓它完整顯示或移到不會被裁的位置。
- 左下事件訊息字級 >= 12px,加半透明深色底讓文字在任何地形上都讀得清楚。
沿用現有金框/木紋主題與 CSS 變數,不要引入新配色。不動遊戲邏輯。
完成後用專案既有的截圖工具輸出 1024x768 的 before/after 並排拼圖到 output/ui-audit/ui-hud-polish.png。
