# T151: ui map labels

Status: done
Accept: npm run verify:quick

## Goal
村莊地圖上的建築名牌(「旅館 Lv.1」「交易所 Lv.1」等)在預設縮放下互相重疊、蓋住別的建築。改成:
- 預設縮放、初始存檔的村莊中,任兩個名牌的矩形不重疊(加一個簡單的避讓:偵測重疊後往上/往旁位移,或縮短為只顯示名稱,滑鼠移到建築上才顯示等級)。
- 名牌不超出畫布可視範圍;未建造的空地名牌用較淡的樣式,與已建造的區分。
- 新增一個檢查器(放 tools/ 或既有檢查腳本目錄,並接進 npm run verify:quick),在初始存檔、預設縮放下計算所有名牌矩形,有任何兩個重疊就失敗。
只改名牌的排版與繪製,不動建築位置、點擊判定、遊戲邏輯。
完成後用專案既有的截圖工具輸出 1024x768 的 before/after 並排拼圖到 output/ui-audit/ui-map-labels.png。
