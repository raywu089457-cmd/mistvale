## Goal
「村莊建設」面板的建築卡片在 1024x768 下成本列擠出卡片邊界、資訊層級不清。改成:
- 成本列(金幣/木材/鐵礦 的 持有/需求)在 1024 寬、四欄排版下完全在卡片內,不裁切、不與相鄰卡片重疊;必要時換成兩行或改三欄。
- 持有量不足的資源用警示色(沿用主題既有的危險色變數),足夠的用一般色;全部足夠的卡片要有明顯可升級/可建造的提示。
- 卡片文字層級:建築名最顯眼,等級次之,成本最小但 >= 12px。
- 卡片 hover / focus / 按下 有一致的回饋(沿用現有金框語言)。
- 面板開啟與關閉加 120-180ms 的淡入+輕微位移轉場,並尊重 prefers-reduced-motion。
不動建造/升級邏輯與數值。
完成後用專案既有的截圖工具輸出 1024x768 的 before/after 並排拼圖到 output/ui-audit/ui-build-cards.png。
