# 裝備經濟設計(EQUIPMENT-ECONOMY)

2026-11-16。對應使用者需求:「設計這些裝備的合理取得管道,還有各自的相關數據計算、分解後產出哪些材料和數量、售出的金額」。
權威資料是 `src/pixel-data.js`:56 件裝備(`EQUIPMENT`,7 職業 × (7 件初始 + 7 件鐵匠升級) = 56)、`RECIPES`(升級件的材料成本)、`MATERIALS`(素材參考價)、`GEAR_DROP`(掉落表)。
遊戲端邏輯在 `src/pixel-game.js`:`grantGear()` / `rollGearDrop()` 與三個發放鉤子(首領、地下城、章節委託)。

## 1. 設計原則

1. **初始裝備不是掉落物**:starter 七件套是「招募即穿」的外觀入門裝。2026-11-16 併入 5024 版本後,starter 數值統一為 **0**(只有外觀 / 售價 / 分解材料),新獵人開局數值跟 5024「六格全空」完全一樣,物品化沒有偷改平衡;數值只來自鐵匠鋪升級件。
2. **升級靠三條路**:自己打造(素材)、跟鐵匠買(金幣)、打王/開寶箱(機率)。三條路都匯入同一個「村莊裝備倉庫」,由玩家決定要穿、要賣、要拆。
3. **賣與拆都不會變成刷錢機**:賣價永遠低於取得成本;拆解只回一半素材。想要金幣就去打怪/接委託,不是把裝備當 ATM。
4. **數值照舊配方,不額外加碼**:craft 的數值沿用 `RECIPES`(作為 5024 的升級件),只調整售價/分解公式;每格 craft 仍強過 0 數值的 starter,不會出現「買了反而變弱」。
5. **掉落率服務節奏**:一般怪 2.5%(撿破爛)、首領 45%(帶回一件升級件)、地下城每 2 層(穩定成長)、章節委託(一次性里程碑)。

## 2. 數值計算(攻擊 / 生命 / 防禦)

裝備數值只有三種:武器給 `atk`,六格防具給 `hp`、`def`(防具不給攻擊)。`updateStats()` 把它們直接加進獵人面板:
`maxHp = (職業 hp + Σ裝備 hp) × 等級 × 稀有度 × 轉世 × 特質`,`attack = (職業 atk + Σ裝備 atk) × …`,`defense = 職業 def + Σ裝備 def + …`。

| 部位 | starter(hp / def) | craft(hp / def) | 成長 |
| --- | --- | --- | --- |
| 武器 | 0(僅外觀) | 攻擊 +7 | 純升級 |
| 頭盔 | 0 / 0 | 6 / 2 | 純升級 |
| 胸甲 | 0 / 0 | 22 / 3 | 純升級 |
| 腰帶 | 0 / 0 | 4 / 1 | 純升級 |
| 腿甲 | 0 / 0 | 10 / 2 | 純升級 |
| 靴子 | 0 / 0 | 4 / 1 | 純升級 |
| 手套 | 0 / 0 | 4 / 1 | 純升級 |
| **全套合計** | **0 / 0 / 0** | **+7 atk / +50 hp / +10 def** | 升級件才有數值 |

- starter 數值是 0:六格初始外觀裝只是讓新獵人有職業造型,不給數值 → 與 5024 的「六格全空」開局完全等價(合併時特別驗證 `test-gear.mjs` 的「starter set adds no stats」)。
- craft 每件都用同一張表(不分職業),數值就是舊版 `RECIPES`(單件皮革護甲 +28/+4 的等價升級),職業差異留給天賦/技能。
- 武器強化(`weaponLevel`,+7%/級)與裝備數值相乘,所以 craft 武器的價值會隨強化放大。

## 3. 售價(賣掉拿回多少金幣)

| 階級 | 公式 | 說明 |
| --- | --- | --- |
| starter | `sell = round(price × 0.4)` | `price` 是該件的參考標價(依部位與職業,8–55 金) |
| craft | `sell = round(材料價值 × 0.8)`,材料價值 = `Σ RECIPES.cost × MATERIALS.price` | 讓「打造 → 賣掉」賠本,材料拿去交易所賣還比較賺 |

craft 售價實算:

| 件 | 材料成本(素材 × 數量) | 材料價值 | 售價 |
| --- | --- | --- | --- |
| 精鐵武器 | 鐵礦×12、木材×6 | 48 | **38** |
| 精鐵頭盔 | 亞麻布×4、鐵礦×6 | 26 | **21** |
| 精鐵胸甲 | 鐵礦×10、獸皮×6 | 48 | **38** |
| 精鐵腰帶 | 獸皮×4 | 12 | **10** |
| 精鐵腿甲 | 鐵礦×6、亞麻布×4 | 26 | **21** |
| 精鐵戰靴 | 獸皮×4 | 12 | **10** |
| 精鐵手套 | 亞麻布×3、獸皮×2 | 12 | **10** |

驗算:`test-gear.mjs` 檢查全部 56 件的售價都符合上表公式,且 craft 售價 > 拆解素材價值(拆不如賣)。

## 4. 分解(拆掉拿回哪些材料、多少個)

| 階級 | 公式 | 例子 |
| --- | --- | --- |
| starter | 依部位給 1–3 個基礎素材(固定表) | 獵弓 → 木材×3、獸皮×1;遊俠兜帽 → 亞麻布×2 |
| craft | `salvage = ceil(RECIPES.cost ÷ 2)`(每種素材取一半,向上取整) | 精鐵胸甲 → 鐵礦×5、獸皮×3;精鐵腰帶 → 獸皮×2 |

規則:
- 分解只回「一半成本」,所以把升級件拆掉重打一定虧;要回收就賣掉。
- starter 的分解素材是新手期最快的布料/獸皮來源(賣掉換 3–22 金,拆掉換 1–3 素材)。
- 倉庫列直接顯示「售 N 金 · 分解 木材×3、獸皮×1」,滑過裝備格也會看到同樣的數字(2026-11-16 加入)。

## 5. 取得管道(每件裝備怎麼來)

| 管道 | 對象 | 成本 / 機率 | 產出去向 |
| --- | --- | --- | --- |
| 招募初始套裝 | 49 件 starter | 免費,新獵人/流浪英雄自動穿 | 直接穿在身上 |
| 野外魔物 | 49 件 starter(隨機 1 件) | 每隻 2.5% | 村莊裝備倉庫 |
| 鐵匠鋪製作 | 7 件 craft | `RECIPES.cost` 素材,需先蓋鐵匠鋪 | `state.gearStock`,等獵人來買 |
| 獵人/流浪英雄選購 | 7 件 craft | 獵人自己付 `RECIPES.price`(60–140 金) | 穿在獵人身上 |
| 森林領主(首領) | 7 件 craft(隨機 1 件) | 每隻 45%;首領冷卻 55 秒 | 村莊裝備倉庫 |
| 地下城寶箱 | 7 件 craft(隨機 1 件) | 每 2 層(第 2、4、6…層) | 村莊裝備倉庫 |
| 章節委託 | 固定件 | 一次性 | 村莊裝備倉庫 |

章節委託指定件(`GEAR_DROP.quest`):
- 第 4 章「鐵匠爐火」→ 精鐵頭盔
- 第 5 章「獵人的新武器」→ 精鐵武器
- 第 7 章「地下城的門後」→ 精鐵胸甲

期望節奏(粗估):
- 一般怪 2.5% → 40 隻怪約 1 件 starter(純回收素材,聊勝於無)。
- 首領 45% + 55 秒冷卻 → 約每 2 分鐘一場,長期約每 4–5 場一件 craft。
- 地下城每 2 層 → 穩定但需要三人小隊活著;這是 craft 的主要來源。
- 委託 3 件 → 前期保證拿到「頭盔→武器→胸甲」的骨幹升級。

## 6. 遊戲端實作

`src/pixel-data.js`:
- `GEAR_SELL_RATE = 0.4`
- `GEAR_CRAFT_POOL`(7 件 craft)、`GEAR_STARTER_POOL`(49 件 starter)
- `GEAR_DROP = { monster:{chance:0.025, pool:GEAR_STARTER_POOL}, boss:{chance:0.45, pool:GEAR_CRAFT_POOL}, dungeon:{every:2, pool:GEAR_CRAFT_POOL}, quest:{3:'craft_helm',4:'craft_weapon',6:'craft_chest'} }`

`src/pixel-game.js`:
- `grantGear(itemId, sourceLabel)` → `newGearItem()` 後推進 `state.gearStorage`,並寫村莊日誌。
- `rollGearDrop(kind)` → 依 `GEAR_DROP` 擲機率、抽池子,回傳 itemId 或 `null`。
- 鉤子:`rewardEnemy()` 首領 → `rollGearDrop('boss')`,一般怪 → `rollGearDrop('monster')`;`floorCleared()` 每 2 層 → `rollGearDrop('dungeon')`;`claimQuest()` → `GEAR_DROP.quest[state.quest.index]`。
- 掉落一律進村莊倉庫,不直接穿;玩家在「獵人 → 裝備」或「庫存 → 裝備倉庫」決定穿上/出售/分解。

## 7. 平衡驗算

- 「打造 → 賣掉」:成本 48 材料價值 → 售 38,虧 10;「打造 → 拆掉」→ 回 24 材料,虧 24。沒有無限金幣迴圈。
- 「交易所買素材 → 打造 → 賣」:素材買價等於 `MATERIALS.price`(鐵礦 3、木材 2…),打造 48 → 賣 38,仍然虧。✔
- 「首領掉落 → 賣」:0 成本拿 38 金,但首領本身需要三人小隊與 55 秒冷卻,期望值遠低於直接打怪的金幣收入。✔
- starter 全套 vs craft 全套:+7/+28/+4 → +10/+55/+13,戰力提升約 42%,代價是 7 件共 565 金或約 188 材料價值。✔

## 8. 未做 / 限制

- 目前沒有「裝備品質/詞條」隨機,56 件都是固定數值;要加隨機品質需要新的存檔欄位與 UI。
- 掉落只看階級,不看地區;之後可以讓雪地/火山掉不同主題件(狼皮→狂戰士、聖光→祭司)。
- 沒有裝備等級需求,新手獵人可以直接穿 craft 件;這是刻意保留的自由度。
- 交易所只收素材,不收裝備;裝備要賣只能透過倉庫的「出售」按鈕。
- 掉落鉤子只在正常擊殺路徑(`rewardEnemy` / `floorCleared` / `claimQuest`)觸發;離線模擬沿用同一條路徑,但離線時不會顯示掉落日誌。
