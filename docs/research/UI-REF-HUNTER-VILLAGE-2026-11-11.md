## 0. 界線（一定要守）

套用的是**設計語言與 UX 模式**：版面結構、資訊層級、互動流程、元件形狀、明暗關係。
**不可以**複製對方的素材：圖示、角色、建築、標誌、文案、字體檔一律用暮影村自己的（`src/` 既有圖示圖集、既有像素字體、既有建築與立繪）。
參考圖只放在 `output/ui-audit/eht-ref/` 供比對，不進 build、不進 git。

## 2. 核心觀察（它為什麼看起來乾淨）

1. **場景是主角，HUD 沒有外框。** 頂部沒有任何橫條或木板，資源數字、圖示、任務文字直接浮在場景上，只靠深色描邊保持可讀。畫面上唯一的實心 UI 是底部頁籤列。
2. **一條底部頁籤列管所有面板。** 五格等寬、大圖示＋小標籤、細直線分隔；選中的那格變成亮色凸起的方塊。面板從頁籤列上方滑出（底部抽屜），頁籤列一直看得到，再點一次或點圓形 X 關閉。
3. **面板是炭黑色，不是木頭或羊皮紙。** 近黑暖灰底、1px 稍亮的邊、卡片內再一圈細線；裝飾幾乎為零，顏色留給內容（建築圖、稀有度、按鈕）。
4. **每張卡片只有一個主按鈕，而且很大。** 整張卡寬的實心色塊（建造＝磚紅、請求＝金棕、鎖定＝灰＋鎖頭），狀態用一行彩色字（完成＝綠）。右上角一顆小金色「i」看詳情。
5. **對話與提示用亮色。** 深色世界上，NPC 對話框是淺灰白底＋深色字，名字是掛在框上緣的深色小標籤——跟深色面板形成明確的「這是故事／那是管理」區分。
6. **選取用貼身的小控制。** 點世界裡的獵人或建築，腳下出現兩顆六角形按鈕（資訊「i」、取消「×」），不開大面板。
7. **字只有一種像素體，粗、白、有描邊。** 靠大小與顏色分層級：標題白、數字白、任務標題粉橘、獎勵金色、完成綠、警告紅。

## 3. 設計代碼（暮影村版）

沿用暮影村的像素字體堆疊，不新增字體檔。新增一組 CSS 變數（名稱可調，值是起點，以實測對比為準）：

| 變數 | 值 | 用途 |
| --- | --- | --- |
| `--hv-ink` | `#14110f` | 面板底、頁籤列底 |
| `--hv-panel` | `#1f1b18` | 卡片底 |
| `--hv-panel-2` | `#2a2521` | 卡片 hover、凹槽 |
| `--hv-line` | `#4a4138` | 1px 邊線、分隔線 |
| `--hv-line-hi` | `#6b5e50` | 卡片內圈亮線、選中邊 |
| `--hv-text` | `#f4ecd6` | 正文 |
| `--hv-text-dim` | `#b3a78f` | 次要字 |
| `--hv-gold` | `#e6b43c` | 金幣、獎勵、「i」鈕 |
| `--hv-quest` | `#f0a08c` | 任務標題、行動鈕標籤 |
| `--hv-ok` | `#8fd16a` | 完成、可升級 |
| `--hv-warn` | `#e0604a` | 不足、危險 |
| `--hv-btn-primary` | `#9a3324`（hover `#b23f2c`，按下 `#7c281c`） | 主按鈕（建造／升級／召喚） |
| `--hv-btn-secondary` | `#8a6420`（hover `#a2772a`） | 次按鈕（請求／查看／資訊） |
| `--hv-btn-disabled` | `#3a3632`，字 `#8a8377` | 停用（加鎖頭圖示） |
| `--hv-tab-active` | `#d9d2bf`，字與圖示 `#231d18` | 底部頁籤選中 |
| `--hv-dialog` | `#e6e4da`，字 `#2a2622` | 對話框、提示 |
| 描邊 | `text-shadow` 四向 1px `#000`（或等效） | 所有浮在場景上的字 |

形狀：圓角 0–3px（像素感，不要大圓角）；邊線 1px 或 2px 整數；不用漸層木紋、不用金箔九宮格、不用 `border-image`；陰影只用硬邊 1–2px 位移。間距以 4px 為單位。

## 4. 版面規格

### 4.1 主 HUD（浮在場景上，沒有頂欄底板）

- **左上**：村莊徽記方塊（現有村徽＋下方小色帶寫難度「初級」，點擊開難度／村莊資訊），右邊緊貼一疊直排資源：每行「圖示＋數字」，金幣、星晶、木材、鐵礦各一行，沒有格子、沒有底板，字白色帶描邊。資源增減的飄字保留。
- **右上第一行**：小圖示列（狀態／增益）＋獵人數「6/8」。
- **右上第二行**：一排無底板的圖示鈕（倉庫、世界地圖、說明、設定等現有功能），每顆點擊熱區 ≥ 40px（手機 ≥ 44px）。
- **日夜**：「第 N 天 · 白天」＋細進度條放在右上圖示列下方或資源疊下方，一行、無底板。
- **任務追蹤（左側，資源疊下方）**：一行標題（`--hv-quest` 色）＋獎勵金幣數；下一行「- 目標 進度 x/y」白字。點擊開委託面板。有可領獎勵時標題閃一下或加小紅點，取代現在中下方的「村長委託的獎勵可以領了」橫條。
- **行動徽章（右側，圖示鈕下方）**：2–3 顆大徽章鈕，圖示在上、兩行標籤在下（`--hv-quest` 色）：例如「獵人 待命／狩獵中」、「進入 競技場」、「召喚 首領」（冷卻時顯示倒數）。取代現在右下角的「召喚首領」方塊。
- **顧問提示**：小頭像＋兩行提示字，放在任務追蹤下方；沿用現有「下一步」提示的內容來源。
- **事件訊息**：左側一至三行，無底框，名字用彩色、其餘白字描邊；舊訊息淡出。
- **操作提示／縮放鈕**：縮放鈕做成右側直排的小圖示鈕（無底板或極淡底）；鍵鼠操作提示只在桌機顯示，縮成一行淡字。

### 4.2 底部頁籤列

- 滿寬、高度桌機 72px／手機 60px＋安全區，底色 `--hv-ink`，上緣 1px `--hv-line`。
- 每個入口等寬（桌機可限制整列最大寬 960px 置中，兩側仍是同色底），大圖示（像素整數倍）＋下方標籤，格與格之間一條 1px 直線（上下各留 12px）。
- 選中：整格變 `--hv-tab-active` 亮色塊並上凸 4px，圖示與字轉深色。hover：圖示提亮。徽章數字（待辦）保留在圖示右上角。
- 暫停／速度／自動儲存狀態移出頁籤列：放到右上圖示列或設定裡，頁籤列只放面板入口。
- 現有 7 個入口（建設、獵人、交易、製作、地下城、競技場、委託）全保留；若手機 7 格太擠（每格 < 48px），把「競技場」與「委託」移到 HUD 的行動徽章與任務追蹤，頁籤列留 5 格。

### 4.3 面板（底部抽屜）

- 面板從頁籤列上方滑出，頁籤列保持可見可切換。手機：滿寬，高度到資源疊下方為止（場景上半仍看得到）。桌機：寬度 `min(960px, 100vw - 32px)` 置中，高度最多 `100vh - 頁籤列 - 96px`。
- 外觀：`--hv-ink` 底、1px `--hv-line` 邊、無標題橫幅插畫（現有 14 張面板橫幅圖拿掉或縮成頁籤列右側的小裝飾，不佔一整列高度）。
- 頂部：左邊是面板內的子頁籤（例如「建築｜裝飾」；選中＝與面板同色並連成一體，未選＝較暗），右上圓形 X（32px，手機 40px）。
- 內容區自己捲動；捲動提示用上下方向的小箭頭，不用現在的「還有內容」漸層條。
- 開關轉場：120–180ms 上滑＋淡入；尊重 `prefers-reduced-motion`。
- Esc、再點同一個頁籤、點 X 都能關閉；現有快捷鍵與指令面板（Ctrl/⌘+K）保留。

### 4.4 卡片

- 通用卡：`--hv-panel` 底、1px `--hv-line` 外邊、內縮 2px 再一圈 1px `--hv-line-hi`（低透明度）。
- 排版由上到下：標題（左上，白，粗）＋右上金色「i」方塊鈕（24px，開詳情）→ 圖（置中，整數倍放大）→ 成本一行（圖示＋數字；不足的數字用 `--hv-warn`）→ 滿寬主按鈕。
- 主按鈕狀態：可建造／可升級＝`--hv-btn-primary`；資源不足＝停用灰但仍顯示缺什麼；等級上限或條件未達＝灰＋鎖頭；已完成＝不放按鈕，改一行 `--hv-ok` 色狀態字。
- 桌機一列 4–5 張、手機 3 張（建設）／2 張（資訊較多的卡）。

### 4.5 獵人列表

- 格狀肖像卡（桌機 6 欄、手機 4 欄）：上方「名字＋稀有度字母（用稀有度色）」，第二行小字「Lv.N 職業」；中間立繪站在一塊依狀態上色的漸層底上（狩獵＝暗紅、休息＝藍灰、用餐＝暖橘、受傷＝紫…沿用現有狀態分類）；立繪下方一行狀態字；底部兩顆並排鈕：「資訊」（寬）＋「定位」（方形，鏡頭跳到該獵人）。
- 現有的排序／篩選保留，放在面板子頁籤列的右側。

### 4.6 世界內選取

- 點獵人或建築：目標腳下出現兩顆六角形小鈕（資訊、取消），鏡頭不跳、不開大面板；點「資訊」才開詳情。目標頭上顯示名字（建築名牌沿用 `src/map-labels.js`，配色換成新代碼：`--hv-ink` 半透明底、白字、無金邊）。
- 鍵盤與觸控都要能操作；六角鈕熱區 ≥ 44px。

### 4.7 對話、提示、確認

- 開場導覽、顧問、NPC 對話：底部亮色對話框（`--hv-dialog` 底、深色字），說話者名字是掛在框上緣的深色小標籤，頭像在框的一側；有動作時在框內排一列「圖示＋小字」的動作鈕。
- toast／提示：小型亮色條，出現在頁籤列上方，不擋場景中央。
- 確認框：炭黑小面板＋兩顆按鈕（主＝磚紅、取消＝灰）。
- tooltip：`--hv-ink` 底、1px `--hv-line`、白字，無箭頭裝飾。

## 5. 驗收標準

1. 主畫面截圖裡，除了底部頁籤列，看不到任何實心的橫條或木板；場景可見面積比改前大。
2. 任一面板截圖裡看不到木紋、金箔框、羊皮紙橫幅；新舊樣式不並存。
3. 所有浮在場景上的字在最亮（雪原）與最暗（夜晚）地形上都讀得清楚（描邊後對比 ≥ 4.5:1）。
4. 字級：正文 ≥ 12px（螢幕實際大小），整個 UI 沒有元素掉回系統字。
5. 觸控熱區：手機 ≥ 44px。
6. 桌機 1440×900、1024×768 與手機 390×844、橫向手機 844×390 都成立。
7. 沒有用到任何《獵魔村物語》的素材或文案。
8. `npm run verify`（完整版）全部通過。
